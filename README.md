# Voice Engine Universal (Mantra)
The shared mechanism of the subtitle that follows the voice, for the Mac (Swift) and the phones (Kotlin). Read SPEC.md.
`swift/PauseSync.swift` + `kotlin/PauseSync.kt`: PAUSE / CONTINUE. `kotlin/Reading.kt`: words, pieces, clock.
Public, no secrets. TAKEOVER.md and LESSONS.md hold the state.
